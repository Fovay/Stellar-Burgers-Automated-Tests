# Sprint 5 — Автотесты Stellar Burgers

## Описание проекта
Проект содержит UI-автотесты для сервиса Stellar Burgers — учебного веб-приложения космического фастфуда.

Тестирование выполнено с использованием Selenium и Python (pytest).

---

## Что тестируется

### Регистрация
- Успешная регистрация пользователя
- Ошибка при вводе короткого пароля

### Авторизация
- Вход через кнопку "Войти в аккаунт" на главной странице
- Вход через "Личный кабинет"
- Вход через форму регистрации
- Вход через форму восстановления пароля

### Личный кабинет
- Переход в личный кабинет
- Выход из аккаунта

### Конструктор
- Переход к разделу "Булки"
- Переход к разделу "Соусы"
- Переход к разделу "Начинки"
